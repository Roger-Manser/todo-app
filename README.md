**Kamera:**

- Foto/Video aufnehmen

**Galerie:**
- Öffne deine Fotosammlung
- Wähle Bilder/Videos
- Wird sofort speichert

- Öffne Dateien auf deinem Computer

**Verwaltung:**
- Hover über Foto → "✕" löschen

## 🆘 Häufige Fragen

**Q: Sind meine Fotos sicher?**
A: Ja! Sie werden Base64-kodiert in deinem privaten GitHub-Repo gespeichert.

**Q: Wie groß können Dateien sein?**
A: GitHub-Limit ist ~100 MB pro Datei. Praktisch: 10-50 MB pro Todo empfohlen.

**Q: Kann ich Fotos wieder löschen?**
A: Ja! Hover über Foto → Klick ✕

**Q: Funktioniert offline?**
A: Ja, aber Fotos synchronisieren nicht, bis du wieder online bist.

**Q: Welche Dateitypen sind erlaubt?**
A: Alle! Bilder (JPG, PNG), Videos (MP4, MOV), Dokumente (PDF, DOCX), etc.
