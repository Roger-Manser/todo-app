# 📝 Todo App v1.0.0 - GitHub Sync

**Eine HTML-Datei. GitHub-Speicherung. Fertig.** ✅

---

## 🚀 Schnell starten

### Schritt 1: GitHub Token (1 Min)
https://github.com/settings/tokens/new → Scope `repo` ✓ → Kopieren

### Schritt 2: HTML öffnen
`index.html` doppelklick

### Schritt 3: Verbinden
- GitHub Benutzername eingeben
- Token einfügen
- Klick "Verbinden"

**Fertig! 🎉**

## 🔑 GitHub Token

1. https://github.com/settings/tokens/new
2. Name: `todo-app`
3. Scope: `repo` ✓
4. "Generate token" → Sofort kopieren!

Token Format: `ghp_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`

---

## 💾 Daten speichern

**In GitHub:**
- Repository: `todo-app-data` (privat)
- Datei: `todos.json`

**Im Browser:**
- LocalStorage für GitHub-Config
- Offline-Zugriff

## 🎮 So geht's

Checkbox klicken → Speichert sofort

"⚙️ Einstellungen" → GitHub-Status, Export, Disconnect
